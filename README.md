# ShadowFox Cybersecurity Internship

## Overview

This repository documents my work throughout the **ShadowFox Cybersecurity Virtual Internship**. It serves as a structured record of the practical tasks, methodologies, findings, and lessons learned while completing the internship.

The primary goal of this repository is to document each task in a **reproducible, professional, and portfolio-ready** manner. Every exercise is treated as a small penetration testing case study, with emphasis placed not only on completing the objective but also on understanding the methodology behind it.

## Documentation Standard

Each task is documented using a consistent structure:

* Objective
* Background
* Scope or Target Information
* Tools Used
* Lab Environment
* Methodology
* Step-by-Step Procedure
* Commands Executed
* Evidence (Screenshots)
* Findings
* Security Analysis
* Lessons Learned
* References (where applicable)

Every guide is written so another learner can reproduce the same results in a similar lab environment.
